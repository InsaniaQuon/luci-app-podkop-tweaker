Fix Init Script

        

            
Problem:

            
OpenWrt normally runs Stubby as user stubby and prepares its writable data directory. This template uses privileged port 53. If the service cannot bind that port due to insufficient privileges, running it as root is one possible fix.

            
One of the solutions:

            
Replace the user with root in the init script:

            
sed -i 's/procd_set_param user stubby/procd_set_param user root/' /etc/init.d/stubby
