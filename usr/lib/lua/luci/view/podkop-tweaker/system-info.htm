⚠ Update info:
  • Podkop: Opens a terminal window (ttyd) for interactive update. Backup is created automatically. Click Refresh after completion.
  • Podkop Tweaker: LuCI will restart during update. Page reloads automatically. Do not power off the router.
  • Argon Theme: Updates the theme and its installed companion packages, preserving settings and typography (with CSS reinjection). A saved update plan can be resumed explicitly. LuCI restarts after completion; the page reloads automatically.
  • Podkop Engine: Updates the patched sing-box engine package from its GitHub releases, rolls back to the previous release or switches the slim/full flavor at the same version. The package is SHA-256-verified before installation; Podkop restarts, so proxying briefly interrupts. No automatic updates.
  • Clear Cache: Clears LuCI internal cache and restarts the web interface. Use if the page shows outdated information after an update.
  • Check for updates: Forces a fresh check for Podkop, Podkop Tweaker, Argon Theme and the Podkop engine. Otherwise each source is checked automatically once a day.
